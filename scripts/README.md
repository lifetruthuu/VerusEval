# Entry points

`reproduce.py` reproduces RQ1–RQ4, `validate.py` verifies data and results, and
`package.py` builds archives from the release whitelist. `plot_gallery.py`
regenerates all metric overview images. `evaluation/evaluate.py`
evaluates file or directory pairs. `generation/` contains the baseline launchers;
`io/` generates and validates I/O suites. See the four documents in `docs/`.
